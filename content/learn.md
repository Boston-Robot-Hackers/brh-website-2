## Getting Started

New to robotics? These resources will give you a solid foundation.

- [MIT OpenCourseWare: Introduction to Robotics](https://ocw.mit.edu/courses/2-12-introduction-to-robotics-fall-2005/) — Classic MIT course covering kinematics, dynamics, and control
- [Robotics Academy (Carnegie Mellon)](https://www.cmu.edu/roboticsacademy/) — Hands-on curriculum for beginners using real robots
- [ROS 2 Tutorials](https://docs.ros.org/en/humble/Tutorials.html) — Official step-by-step introduction to the Robot Operating System
- [Articulated Robotics YouTube Channel](https://www.youtube.com/@ArticulatedRobotics) — Practical ROS 2 and robot building from scratch
- [The Robotics Back-End Blog](https://roboticsbackend.com/) — Focused tutorials on ROS, Python, and embedded systems

## Programming & Software

Core software skills every roboticist needs.

- [Python Robotics (GitHub)](https://github.com/AtsushiSakai/PythonRobotics) — Sample implementations of robotics algorithms in Python
- [ROS 2 Documentation](https://docs.ros.org/en/humble/) — Full reference for nodes, topics, services, actions, and more
- [Gazebo Simulation](https://gazebosim.org/docs) — Industry-standard robot simulation environment
- [MoveIt 2](https://moveit.picknik.ai/main/doc/tutorials/tutorials.html) — Motion planning framework for manipulation
- [Nav2 (Navigation Stack)](https://nav2.ros.org/) — Complete autonomous navigation for mobile robots

## Hardware & Electronics

Build and wire the physical side of your robot.

- [SparkFun Electronics Tutorials](https://learn.sparkfun.com/) — Guides on sensors, motors, microcontrollers, and more
- [Adafruit Learning System](https://learn.adafruit.com/) — Hands-on electronics tutorials for makers
- [FIRST Robotics technical guides](https://docs.wpilib.org/en/stable/) — WPILib docs covering motor controllers, sensors, and CAN bus
- [Hackaday.io Projects](https://hackaday.io/projects) — Community-shared hardware builds and schematics
- [Open Source Robotics Hardware (OSRF)](https://www.openrobotics.org/) — Open-hardware robot platforms and reference designs

## Computer Vision & Perception

Teach your robot to see and understand its environment.

- [OpenCV Python Tutorials](https://docs.opencv.org/4.x/d6/d00/tutorial_py_root.html) — Comprehensive guide to image processing and computer vision
- [YOLO Object Detection](https://docs.ultralytics.com/) — Fast real-time object detection with Ultralytics YOLO
- [Depth Camera Guide (Intel RealSense)](https://dev.intelrealsense.com/docs/ros2-wrapper) — Point clouds and depth sensing with ROS 2
- [Point Cloud Library (PCL)](https://pcl.readthedocs.io/projects/tutorials/en/latest/) — 3D perception and processing tutorials
- [Kalman Filters Explained](https://www.bzarg.com/p/how-a-kalman-filter-works-in-pictures/) — Visual intuition for state estimation

## Motion Planning & Navigation

Move your robot from point A to point B safely and efficiently.

- [Probabilistic Robotics (Thrun, Burgard, Fox)](http://www.probabilistic-robotics.org/) — The definitive textbook on robot state estimation and SLAM
- [Planning Algorithms (LaValle)](http://lavalle.pl/planning/) — Free textbook covering sampling-based and search-based planning
- [Nav2 Concepts](https://nav2.ros.org/concepts/index.html) — Behavior trees, costmaps, and planner plugins explained
- [A* and Dijkstra Visualizer](https://www.redblobgames.com/pathfinding/a-star/introduction.html) — Interactive introduction to path planning algorithms
- [OMPL: Open Motion Planning Library](https://ompl.kavrakilab.org/) — Sampling-based planners used in MoveIt and many research systems

## AI & Machine Learning for Robotics

Apply modern machine learning to robot perception and control.

- [Deep Learning Specialization (Coursera)](https://www.coursera.org/specializations/deep-learning) — Andrew Ng's foundational deep learning course sequence
- [Spinning Up in Deep RL (OpenAI)](https://spinningup.openai.com/en/latest/) — Practical introduction to deep reinforcement learning
- [Hugging Face LeRobot](https://huggingface.co/lerobot) — Open-source real-world robot learning models and datasets
- [Stanford CS231n: CNNs for Visual Recognition](http://cs231n.stanford.edu/) — Computer vision with deep learning
- [Google Robotics Research](https://research.google/teams/robotics/) — Papers and projects from Google's robotics lab

## Key Academic Papers

Landmark papers every serious roboticist should know.

- [A Formal Basis for the Heuristic Determination of Minimum Cost Paths (Hart, Nilsson, Raphael 1968)](https://ieeexplore.ieee.org/document/4082128) — The original A* paper
- [ORB-SLAM2 (Mur-Artal & Tardós, 2017)](https://arxiv.org/abs/1610.06475) — Real-time monocular, stereo, and RGB-D SLAM
- [RT-2: Vision-Language-Action Models (Google DeepMind, 2023)](https://arxiv.org/abs/2307.15818) — Robotics transformer using web-scale vision-language pretraining
- [Fast and Furious: Real Time End-to-End 3D Detection (Luo et al., 2018)](https://arxiv.org/abs/1803.05758) — Efficient 3D object detection for autonomous vehicles
- [Rapidly-exploring Random Trees: A New Tool for Path Planning (LaValle, 1998)](http://msl.cs.illinois.edu/~lavalle/papers/Lav98c.pdf) — Foundational RRT paper
